# AI-Complaint-Intelligence-Platform

🚀 Built my first AI Complaint Intelligence Dashboard using Python & NLP

I analyzed 100,000+ AI app reviews to discover what users complain about most and how they emotionally react to AI products.

This project includes:

• Sentiment Analysis using NLP
• Complaint Classification
• Interactive Streamlit Dashboard
• AI-generated business insights
• Data visualization with Python

🔍 Main findings:
• Server instability was the #1 frustration
• Usage limits strongly reduced satisfaction
• Accuracy issues appeared frequently
• Privacy concerns created highly emotional reactions

Tech stack:
Python • Pandas • Streamlit • Matplotlib • VADER Sentiment Analysis

This project helped me practice:
• Data cleaning
• NLP
• Data storytelling
• Dashboard development
• Real-world analytics workflows

Excited to keep building more data analytics and AI projects.
